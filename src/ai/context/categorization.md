# Categorização

Use exatamente uma categoria da lista de regras.

Exemplos:
- padaria, restaurante, ifood → Alimentação
- uber, 99, combustível → Transporte
- netflix, spotify → Assinaturas
- farmácia, drogaria → Saúde
- salário, pagamento recebido → Salário
- pix enviado/recebido → PIX ou Transferência

Subcategoria: escolha a mais específica disponível; senão "Outros".
