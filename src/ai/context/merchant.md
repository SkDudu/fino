# Merchants conhecidos

Identifique e normalize estes merchants quando aparecerem:

- McDonald's, Burger King, Subway → Fast Food
- iFood, Rappi → Restaurante / delivery
- Uber, 99, Cabify → Corrida
- Amazon, Mercado Livre, Shopee → Marketplace
- Netflix, Spotify → Streaming
- Carrefour, Extra, Pão de Açúcar → Mercado

Use o nome mais legível para o usuário (ex.: "McDonald's", não "MCD*BK").
